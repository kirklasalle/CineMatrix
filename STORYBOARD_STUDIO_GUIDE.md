## 🚀 Quick-Start Guide

### 1. Launching the Application
Run the master desktop launcher from the project root:
- **Windows Batch:** Double-click `start_storyboard.bat`
- **PowerShell:** Run `./start_storyboard.ps1`

The launcher boots the FastAPI backend on `http://127.0.0.1:8000`, the React/Vite frontend on `http://localhost:5173`, and opens your default browser automatically.

### 2. Supported Ingestion Formats
| Format | Extension | Description |
|:---|:---|:---|
| **Final Draft** | `.fdx` | Industry standard XML screenplay format with scene elements & character tags. |
| **Fountain** | `.fountain`, `.spmd` | Plain-text screenplay markup with forced headings and title pages. |
| **Microsoft Word** | `.docx` | Standard production documents with paragraph parsing. |
| **Adobe PDF** | `.pdf` | Screenplay PDFs parsed with character line extraction. |
| **Comic Archives** | `.cbz`, `.cbr` | Comic book ZIP/RAR archives with embedded `ComicInfo.xml`. |
| **ePub Books** | `.epub` | Digital publications partitioned by chapters. |

## 🎨 Master Visual Style Vault (16 Styles)

When generating storyboard frames or graphic novel pages, select from 16 curated aesthetic styles:
1. **Oscar Prestige (Default):** 35mm anamorphic film, volumetric lighting, rich shadows, and Panavision lens flares.
2. **Neon Cyberpunk:** High-contrast neon hues, rain-soaked reflections, and holographic grit.
3. **Nordic Noir:** Desaturated cold blues, misty Nordic landscapes, and high textural realism.
4. **Golden Age Technicolor:** Vibrant saturated primaries and 1950s Hollywood soundstage lighting.
5. **Vintage Noir (1940s):** High-contrast black and white chiaroscuro with Venetian blind shadows.
6. **Anime / Studio Ghibli:** Hand-painted lush watercolor backgrounds and expressive anime character design.
7. **Graphic Novel / Dark Horse:** Heavy black inks, cross-hatching, and dramatic comic book lighting.
8. **Modern Manga:** Crisp monochrome screen-tones, dynamic speed lines, and expressive panel framing.
9. **Sci-Fi IMAX:** Epic widescreen scale, clean industrial surfaces, and stark celestial lighting.
10. **Gothic Victorian:** Sepia mist, ornate ironwork, candlelight, and Victorian atmospheric horror.
11. **Western 70mm:** Sun-bleached dust, deep warm amber palettes, and expansive desert horizons.
12. **80s VHS Retro:** Subtle chromatic aberration, analog CRT glow, and warm vintage saturation.
13. **Pixar 3D Animation:** Stylized expressive 3D character design with soft subsurface scattering.
14. **Documentary Handheld:** Raw natural lighting, subtle grain, and authentic cinema verite framing.
15. **Surrealist Dream:** Dali-esque impossible architecture, glowing nebulas, and floating geometry.
16. **Minimalist Storyboard:** Clean crisp charcoal pencil line art with subtle ink washes.

## 📦 Master Export Formats

From the **Master Export Suite** dropdown in any project:
- **16:9 Landscape PDF Presentation Deck:** Full-bleed cinematic slide deck with director notes and shot lists.
- **Full ZIP Frame Archive:** High-resolution PNGs organized cleanly into `/frames/` with manifest.
- **Master Animatic Video Reel (`.mp4`):** Continuous video reel with 2-second director title card and lower-third slates.
- **Comic Book Archive (`.cbz`):** Compliant comic book archive with embedded `ComicInfo.xml`.
- **Character Look-Book PDF:** Executive casting profiles, wardrobe traits, and prompt consistency seeds.
- **300 DPI Graphic Novel Print Edition (`.pdf`):** Multi-panel print pages with dialogue balloons and margins.
- **Fountain Script (`.fountain`):** Re-exported plain-text screenplay format.
- **Production CSV Shot List:** Spreadsheet with scene numbers, shot types, camera angles, and intensity scores.

## ⌨️ Presentation Keyboard Shortcuts

| Key | Action |
|:---|:---|
| **Space** or **→** | Advance to next scene / frame |
| **←** | Return to previous scene / frame |
| **F** | Toggle Fullscreen Keynote Mode |
| **A** | Audition speaking character voice / dialogue |
| **M** | Trigger motion animatics playback |
| **Esc** | Exit Presentation / Video Modal |
